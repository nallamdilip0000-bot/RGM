# RGM - Personal Project Milestone Tracker

Full-stack personal project milestone tracker for students, faculty, and administrators built with Node.js, Express, and Firebase Firestore.

## Features
- **Student Portal**: Manage project milestones, submit tasks, monitor deadlines, and view individual evaluation rubrics.
- **Faculty Portal**: Review student milestone submissions, score rubrics, and provide feedback.
- **Admin Portal**: System overview, user management, and project tracking.
- **Automated Deadline Notifications**: Email & In-App alerts for upcoming and overdue milestones.

## Setup & Running
1. Clone the repository:
   ```bash
   git clone https://github.com/nallamdilip0000-bot/RGM.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Configure environment variables in `.env` (refer to `.env.example`).
4. Start the application:
   ```bash
   npm start
   ```
